# 🛡️ MuleShield Investigator

### AI-Assisted Financial Crime Analysis & Money-Trail Investigation Platform

<p align="center">
  <strong>Rajasthan Police Hackathon | Problem Statement PS05</strong>
</p>

MuleShield Investigator is a research prototype designed to support financial crime investigations through automated bank statement analysis, UTR-based transaction tracing, suspicious account pattern detection, account network analysis, and structured evidence reporting.

## 🎯 Problem Statement

Financial investigations often require investigators to manually analyse multiple bank statements, trace transactions across accounts, identify suspicious fund movements, and prepare structured reports.

MuleShield Investigator aims to bring these analytical capabilities into one integrated investigation workspace.

## 🚀 Key Features

- **Bank Statement Analysis:** Import PDF and Excel statements.
- **Transaction Normalization:** Standardize transaction records.
- **UTR-Based Money Trail:** Identify matching transfers across accounts.
- **Account Network Analysis:** Visualize account-to-account fund movement.
- **Suspicious Pattern Detection:** Flag potential mule-account indicators.
- **Digital Indicator Validation:** Validate IP addresses and domains.
- **Case Report Generation:** Produce structured PDF reports.

## 🏗️ Technology Stack

- Python
- Streamlit
- Pandas
- NetworkX
- PyMuPDF
- ReportLab
- OpenPyXL

## ⚠️ Project Status

Research prototype under development. Detection outputs are investigative indicators, not proof of criminal activity. Use synthetic data for public demonstrations.
